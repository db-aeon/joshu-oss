Plain-language summary: [0.1.68-user-summary.md](0.1.68-user-summary.md).

0.1.68 is the first open-source release since 0.1.65, so these notes cover three releases (0.1.66 to 0.1.68).

## Docker Compose is deprecated

A box now runs as one container from the sandbox image, started with one `docker run` command. The container runs the Joshu stack, Caddy as an internal router on plain HTTP port 8080, the voice service, the instance agent, and, when you give it a token, `cloudflared`. You give the box its public HTTPS hostname with a Cloudflare Tunnel or with a reverse proxy of your own in front of `127.0.0.1:8080`. The box keeps all its data on one disk, under the folder that `JOSHU_DATA_ROOT` names.

Single-container mode is now the only supported way to run a box. The Docker Compose setup still works in 0.1.68, and nothing changes for a Compose box when you upgrade it. A later release will remove the compose file, the separate Caddy container that gets the TLS certificates, and the separate voice and instance agent images. Please move your box to single-container mode before then.

- New box: follow [Run a box](../self-host.md#run-a-box) in the self-host guide.
- Compose box: follow [Move a box from Docker Compose](../self-host.md#move-a-box-from-docker-compose). The move is a one-time copy of the Compose volumes to the data root, and the hostname of the box stays the same.
- The reasons for the decision are in [system-overview.md](../technical-reference/system-overview.md).

Details of single-container mode:

- The mode is on when `JOSHU_DATA_ROOT` is set. Without it, the image starts as a Compose stack container, as before.
- The config file is `<JOSHU_DATA_ROOT>/secrets/instance.env`.
- Each service writes its log to `<JOSHU_DATA_ROOT>/logs/<service>.log`, with a UTC time on each line. A log over 20 MB moves to `.log.1`, so each service uses at most about 40 MB.
- The health check probes port 8080, and the ready endpoint of `cloudflared` when the tunnel is on.
- `GET /joshu/api/instance/version` has the new field `runtime`, with the value `single-container` or `compose`.
- The start script restarts the box in place on SIGUSR1, without a stop of the container. The instance agent uses the restart for `restart`, `rotate_secrets`, and `set_aroz_password`. It refuses `update`, `rollback`, and `deprovision` in this mode, because you update a box by starting a new container from a newer image.
- A box can't go back to an image older than 0.1.68 after the move, because older images don't know the data root. The hotfix overlay does not work in this mode.

## What changed since 0.1.65

### Models

The release now sets the models of a box. Before, a model value in `instance.env` won over the model of the image through every upgrade.

| Use | Before | Now |
|---|---|---|
| Companion | `deepseek/deepseek-v4.1-flash` | `deepseek/deepseek-v4.1-flash-1017` |
| Small classifiers (mail triage, action guard, realtime goal router, Day 0) | `openai/gpt-5.4-nano` | `anthropic/claude-haiku-5.5` |
| Hindsight, session search, skills merge | `google/gemini-3.1-flash-lite` | `google/gemini-3.5-flash-lite` |

- `JOSHU_HERMES_MODEL` and `HINDSIGHT_API_LLM_MODEL` are now only overrides for one box. At the start, the box removes either line from `instance.env` when its value is one of the old default models, and it removes cron job pins to those models. Any other value stays.
- The small classifiers share the constant `JOSHU_OPENROUTER_CLASSIFIER_MODEL`, and each keeps its own env override.
- If your OpenRouter account has a list of allowed models, add the three new models before you upgrade, or every request with them fails.

### Web search with You.com

A box with a You.com key (`YDC_API_KEY`) now uses You.com for the companion tools `web_search` and `web_extract`, and for the web search of Research reports and recurring reports. Exa answers a search or a page that You.com could not answer. A box with no You.com key works as before, on Exa.

- The new Hermes plugin `joshu-web-you` holds no key. It posts each call to the new routes `POST /joshu/api/web/search` and `POST /joshu/api/web/extract`, which accept only the desktop session of the owner or a direct localhost request.
- Breaking change: a Research report request with no `web_provider` no longer always uses Exa, because the box decides. `web_provider: "exa"` forces Exa.

### Research report sources

Composio retired the search toolkit that gave Research reports their news, research papers, SEC filings, and stock prices. In 0.1.68 these sources come through the content router.

- News, research papers, and SEC filings are content goals, as the social sources are. The box finds a provider endpoint in the router catalog by itself, so it can find another one when a provider goes away.
- Stock prices use the fixed endpoints `tiingo.daily.prices` and `tiingo.daily.meta`, and the price page shows daily closes.
- These sources need the content router (`JOSHU_ROUTER_API_KEY`), and each call takes a small amount from your router wallet. Without the router, a report has the web search only, and its source list says why the other sources are missing.
- The Composio search client and `JOSHU_COMPOSIO_SEARCH_TOOLKIT_VERSION` are removed. `COMPOSIO_API_KEY` is still used for the live Gmail search.
- The route cache no longer turns a goal kind off for a week after one failed route. The box removes a cached route after three faults in a row, and faults of one route within one hour count as one fault. The box then learns a new route in the same report.

### Mail and the companion

- An outsider can no longer make the companion act without the owner. A thread is authorized only when the owner sent the email, the owner already wrote in the thread, or the companion already emailed that outsider. A meeting request from an outsider gets one question to the owner first. A reply to an outsider on a thread that is not authorized gets `403 mail_send_not_authorized`.
- The owner completion text keeps words and paragraphs whole, e.g., "saved as .png" and "Est. 1636", and a long text message splits between paragraphs.

### Hermes

- At each start, the box deletes Kanban and cron sessions whose last message is older than 30 days from the Hermes session history (`state.db`). Other sessions, e.g., jChat and Slack, stay. The start waits at most 240 seconds for the delete, so a box with a large file can need two or three starts to finish.
- Hermes memory gets more room: 6,000 characters for `MEMORY.md` and 4,000 for `USER.md`. HERMES.md tells the companion to keep owner rules in `USER.md`.
- A realtime goal worker gets a warning when 15 steps or fewer are left. When it reaches the step limit, its last summary is kept as a note on the task, so the next run goes on from there.

### Health report

- The new component `capabilities` checks whether web search, Hindsight recall, Hindsight saves, and the content router work. It runs 5 minutes after the start and then every 6 hours, and it never changes `healthy`.
- The `hindsight` entry now shows `enabled` and a `reason` when Hindsight is off or does not answer.

### Desktop

- ArozOS moves to upstream v3.0.2, with the new File Manager, System Settings, and phone page. The box starts ArozOS with its TURN relay and Docker management service off, and the 30 new stock apps are hidden.
- jNotes uses the full width of its window.
- On a phone, the browser handoff page allows a pinch to zoom.
- Setup tips on board `ea-onboarding` close by themselves when the box sees that the step is done. The tip to save the box number is retired.

### Security

- ArozOS is built with Go 1.26.11 (CVE-2025-68121 in `crypto/tls`), with newer `x/net`, `x/image`, `go-git`, `go-billy`, and `klauspost/compress`.
- The Hermes venv has `pyasn1` 0.6.5, `tornado` 6.6.1, `litellm` 1.108.10, and `filelock` 4.2.10.
- The lockfiles have `hono` 4.13.19, `@hono/node-server` 2.1.8, `fast-xml-parser` 5.12.1, and `qs` 6.17.1.
- `pnpm-lock.yaml` and `pnpm-workspace.yaml` are removed, because no build used them.

### Instance agent

The instance agent keeps sending heartbeats after a failed round. Before, one failed request could make it exit or stop the heartbeats until the next restart.

## Upgrade notes (from 0.1.65)

No database migrations.

To move to single-container mode, follow [Move a box from Docker Compose](../self-host.md#move-a-box-from-docker-compose). To stay on Compose for this release, upgrade as before. First, set `JOSHU_RELEASE_VERSION=0.1.68` and the three image refs of 0.1.68 in `/etc/joshu/instance.env`. Second, pull the images and run `install-host-bundle.sh` from the 0.1.68 image. Third, recreate `caddy`, `joshu-stack`, and `voice-realtime`. The commands are in the [0.1.65 notes](0.1.59-0.1.65.md#upgrade-notes-from-0159), with the version changed.

What happens at the first start:

- The box removes old default models from `instance.env` and old model pins from cron jobs.
- The session prune deletes old Kanban and cron sessions, so the first start can take up to 240 seconds longer.
- The skills seed merges the changed factory skills: `ea-mail-ingress`, `ea-scheduling`, `ea-owner-reply`, `ea-onboarding`, `research-report`, `realtime-goal`, and `joshu-content-router`.
- The route cache drops its "no route" records, and the box learns those goal kinds again at their next use.
- The first use of each of the goals "News articles", "Research papers", and "SEC filings" makes two model calls.

New and changed environment variables:

| Variable | Default | Effect |
|---|---|---|
| `JOSHU_DATA_ROOT` | none | Turns on single-container mode, and names the folder of the persistent disk. |
| `CLOUDFLARE_TUNNEL_TOKEN` | none | Single-container mode only. Starts `cloudflared` in the container. |
| `YDC_API_KEY` | none | You.com key. With it, the box uses You.com for web search, with Exa as the fallback. |
| `JOSHU_SESSION_PRUNE_DAYS` | `30` | Age of the Kanban and cron sessions to delete. `0` turns the delete off. |
| `JOSHU_SESSION_PRUNE_SOURCES` | `kanban,cron` | Session sources that the prune deletes. |
| `JOSHU_SESSION_PRUNE_TIMEOUT_SEC` | `240` | How long the start waits for the prune. |
| `JOSHU_HERMES_MODEL`, `HINDSIGHT_API_LLM_MODEL` | release models | Now only overrides for one box. |
| `JOSHU_COMPOSIO_SEARCH_TOOLKIT_VERSION` | | Removed. |

Rollback: a rollback of a Compose box to 0.1.65 needs `HINDSIGHT_API_LLM_MODEL=google/gemini-3.1-flash-lite` written back into `instance.env` by hand, because the older start script has no default for it. A box in single-container mode can't roll back to an image older than 0.1.68.

## Known issues

- In single-container mode, the Hermes Admin desktop shortcut can still point at the dashboard host, which the container does not serve.
- A new email from the companion that names no thread is not checked by the outsider rule.
- A goal kind with no working provider endpoint costs one route model call and one router call in each report.
- In the first test, research papers came from an arXiv search, which has fewer fields than Google Scholar, so a report on medicine or social science can get fewer papers than before.
- A box with no Exa key gets only the short passages that You.com returns for news and paper pages.
